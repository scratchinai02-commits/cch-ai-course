# 行政文件研讀與 NotebookLM 影音製作

## 輸入與任務範圍

- 預設文件：`員工請假管理要點_2026修訂版.docx`；忽略 `~$` 開頭的 Word 暫存檔。
- 依使用者指定產出研讀結果、簡報或影片；只要求影片時，不另外生成簡報。
- 本資料夾示範資料皆為虛構，成果標示「僅供院內教育訓練使用」。
- 執行簡報或影片任務時，讀取 [YAML 設計範本](references/notebooklm-design.yaml)，依來源與使用者風格需求調整。

## 1. 開啟內建瀏覽器與登入

1. 使用可用的瀏覽器工具開啟可見的內建瀏覽器，前往 `https://notebooklm.google.com/`。可接受服務自行導向的官方網址；不要硬編碼既有分頁 ID。
2. 優先沿用本次任務的現有筆記本；確認頁面顯示登入帳戶。需要登入或驗證時依工具規則操作，需使用者接手的步驟再請其處理。
3. 每次操作後查看最新畫面或可及性狀態，再決定下一步。需保留的筆記本分頁標記為交付成果。

## 2. 取得彰基官方 LOGO

1. 先找使用者提供的 LOGO；沒有時，搜尋彰基官方網站 `cch.org.tw` 及其子網域的院徽、識別素材或公共關係部素材庫。
2. 官方查找起點：`https://dpt.cch.org.tw/layout/layout_3/about.aspx?ID=8730&Key=222`。頁面與素材網址可能異動，執行時重新確認，不把網頁網址當成圖片檔。
3. 下載可用的官方圖檔至 `assets/`，記錄來源頁、原始圖檔網址、取得日期及公開使用規範於 `assets/logo-source.md`。開啟圖片確認是彰基院徽與院名，避免誤取分院或科室專屬標誌。
4. 保留原始比例、色彩與完整院名，不由生成模型重畫 LOGO。找不到合適圖檔時如實回報並預留 LOGO 位置，不使用仿製標誌。
5. 可支援圖片來源或品牌素材上傳時加入圖檔；僅在 YAML 寫入本機路徑不會將圖片傳給 NotebookLM。生成前確認介面實際收到素材。

## 3. 建立筆記本與上傳文件

1. 新增或沿用任務筆記本，從 Sources／來源 → 新增來源 → 上傳檔案，選取指定文件。
2. 等待來源處理完成，確認檔名與來源數量，並開啟來源核對內容可讀。
3. 文件是內容依據，LOGO 是視覺素材，不以 LOGO 圖片推論制度。只能使用文件內容；沒有寫的回答「來源未提及」。

## 4. 有來源依據的研讀

使用者要求行政研讀時產出：

- 100 字摘要。
- 5 個重點，每點標註引用條次。
- 同仁需配合的待辦事項清單。
- 新人 FAQ 8 題，每題附引用；「來源未提及、需洽人資處」的問題另列。

點引用編號回原文核對至少 2 處，尤其是假別天數、期限與證明文件。影音中涉及規定的數字也應核對，不將訓練示範內容當成現行正式規範。

## 5. 套用 YAML 生成簡報或影片

- YAML 是給生成模型看的自然語言設計規範，不宣稱是 NotebookLM 官方 API 或保證精準遵守的設定格式。
- 採 `關鍵字: 內容`、冒號後空格、兩個空格縮排、不用 Tab；色碼以引號包住；清單使用 `-`。`#` 註解只放給人看的說明，必要要求寫成欄位內容。
- 指令包含四部分：視覺主軸（色彩與字體）、共同網格與留白、可變版面目錄、設計紅線與選版邏輯。
- 預設風格為「質感知性流動絲線風」，配色是本任務建議，不能稱為官方品牌色；使用者提供風格參考時，先分析色彩、層次、字體與版面再改寫 YAML。
- 簡報：Studio → 簡報 → 自訂，選繁體中文與適當長度，將調整後 YAML 貼入設計／內容指令欄。
- 影片：Studio → 影片摘要 → 自訂，預設繁體中文說明影片，將調整後 YAML 貼入重心／自訂主題欄。若介面有製作人附註預覽，可用來確認內容與品牌要求。
- 依當前介面操作，不假設按鈕名稱永遠相同。確認來源、語言與格式後生成一次；已有相同任務正在生成時沿用並等候，避免重複消耗額度。

## 6. 等候、檢查與送回成果

1. 持續檢查生成狀態，定期簡短回報；錯誤時查看原因，不無限重試或自行加購。若服務持續處理，保留筆記本並明確說明尚未完成。
2. 完成後開啟預覽，核對繁體中文、內容、條次、數字、訓練註記，以及 LOGO 是否確實存在、清晰且未變形。不要只因 YAML 寫了 LOGO 就宣稱已置入。
3. 若模型未正確置入 LOGO，優先使用可編輯成果後製嵌入原圖；在工具能力不足時說明限制，不冒充已完成品牌要求。調整後重新檢查。
4. 下載使用者要求的影片或簡報到本資料夾；確認檔案存在、大小合理且可開啟。影片取得實際檔案後才能稱為「已送回影片」。
5. 回覆本機成果連結與筆記本網址；依瀏覽器工具要求提供完成畫面的截圖。下載失敗時保留可操作的筆記本與具體阻礙，不把生成中狀態當完成。

## 📱 手機版使用方式（ChatGPT／Gemini App）
1. 打開 ChatGPT 或 Gemini，按「＋」上傳這份檔案，以及範例資料（Excel／CSV／PPT／Word／圖片）。
2. 輸入：「請依照這份檔案執行」。
3. 沒看到可下載的檔案時，輸入：「請給我 Excel 檔」或「給我 CSV」。

## 設計範本：notebooklm-design.yaml（貼到 NotebookLM 自訂欄位）

```yaml
# 貼入 NotebookLM 自訂欄位的自然語言規範；非官方設定結構。
任務:
  主題: "員工請假管理要點 2026 修訂版"
  輸出: "繁體中文說明影片；要求簡報時改為簡報投影片"
  受眾: "院內同仁與新進員工"
  內容依據: "僅使用已上傳行政文件；沒有寫的標示來源未提及"
  重點:
    - "適用對象與假別"
    - "申請流程、期限與證明文件"
    - "同仁待辦與常見問題"
  引用: "重要規定標示原文條次，不杜撰條號、天數或核准權限"
  註記: "虛構示範資料，僅供院內教育訓練使用"
品牌素材:
  LOGO來源: "使用另行上傳並核對的彰化基督教醫院官方 LOGO 圖檔"
  呈現: "封面與結尾置入原圖；其餘頁面可於右上角小尺寸呈現"
  保護: "保留原色、比例與完整院名，四周留白，不重畫、不裁切、不拉伸"
  無法使用原圖時: "保留乾淨位置供後製，禁止自行生成相似院徽"
全體設計設定:
  視覺主軸: "質感知性流動絲線風；專業、清晰、溫暖"
  配色:
    背景: "#F7F8F5"
    主文字: "#243A35"
    重點色: "#387565"
    輔助色: "#C8B98B"
    說明: "此為建議視覺色盤，並非經認證的彰基官方品牌色"
  字體: "可用的繁體中文無襯線字體；標題中粗、正文正常字重，避免過細小字"
  字級: "依畫面比例建立明顯層級，手機觀看仍可讀"
  裝飾: "低對比細絲線僅作背景，不穿過文字、圖表或 LOGO"
共同網格:
  畫面比例: "16:9"
  對齊: "一致的十二欄網格，標題與正文共用左側基準線"
  安全邊界: "四邊至少保留畫面寬度的百分之五"
  留白: "每頁聚焦一個核心訊息，不以文字塞滿畫面"
版面目錄:
  - 名稱: "封面"
    配置: "大標題、修訂版本、官方 LOGO 與訓練註記"
  - 名稱: "單一重點"
    配置: "大字結論搭配簡潔圖示與來源條次"
  - 名稱: "左右對照"
    配置: "適用於假別或條件比較；欄位與單位一致"
  - 名稱: "流程"
    配置: "申請、檢附、送審等步驟依來源排序；不新增來源未載程序"
  - 名稱: "待辦清單"
    配置: "簡短動詞句，標示期限與應備文件"
  - 名稱: "情境問答"
    配置: "問題與答案分層呈現；答案附條次"
  - 名稱: "結尾"
    配置: "重點回顧、原文查閱提醒、官方 LOGO 與訓練註記"
影片呈現:
  旁白: "自然清楚的繁體中文，數字、期限與假別逐一準確說明"
  節奏: "每個場景講清楚一件事，給觀眾足夠閱讀時間"
  轉場: "簡潔淡入淡出，避免炫技效果"
設計紅線與邏輯:
  - "依內容選擇版面，不機械重複同一配置"
  - "禁止高飽和螢光色、純黑背景與大量立體裝飾"
  - "以清晰可讀優先，文字與背景保持足夠對比"
  - "禁止虛構院方背書、制度條文與官方品牌規範"
  - "不得為美化而省略重要條件、例外或期限"
```
