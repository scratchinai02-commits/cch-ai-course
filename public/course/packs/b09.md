# 報告與儀表板（Codex）

## 輸入
- `data.csv`／`data.xlsx`（Skill 03）、`報告範本.pptx`（版面與章節）

## 步驟
1. 依範本章節，在 index.html 加入「報告」分頁：摘要卡、明細表、長條圖（純 SVG 或 canvas）。
2. 「列印報告」按鈕：只印報告內容，頁首「彰化基督教醫院」與報告日期。
3. （進階）依範本產生 `output/報告.pptx`，章節與範本相同。
4. 自我檢查：列出報告中每個數字的來源欄位與公式。

## 規則
- 所有數字由程式依資料計算，不可寫死。

---
## 📱 手機版使用方式（ChatGPT／Gemini App）
1. 打開 ChatGPT 或 Gemini，按「＋」上傳這份檔案，以及範例資料（Excel／CSV／PPT／Word／圖片）。
2. 輸入：「請依照這份檔案執行」。
3. 沒看到可下載的檔案時，輸入：「請給我 Excel 檔」或「給我 CSV」。
