# 比率與達成率計算器（Codex）

## 輸入
- `data.csv`（Skill 03 示範資料）；規格見 `data.xlsx`「說明」工作表

## 步驟
1. 建立單一檔案 `index.html`：可上傳 CSV 或貼上表格，並有「載入示範資料」按鈕（把 data.csv 內容寫在程式內）。
2. 依「說明」工作表的指標逐列計算（小數 2 位；分母為 0 顯示「分母為0待確認」，基準日 2026-10-23）。
3. 介面繁體中文、主色 #008927；純 HTML＋JavaScript，不連網、不需要 API Key。
4. 完成後用示範資料自我測試，回報第 1 列的計算結果。

## 驗收
- 與 data.xlsx「正確答案」工作表一致。
